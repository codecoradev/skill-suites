# Indonesian Localization — Humanizer

Bahasa Indonesia punya AI tells sendiri. Section ini extend pattern di SKILL.md utama ke konteks bahasa Indonesia, khususnya untuk penulisan casual (WhatsApp, chat, pesan bisnis personal).

## Indonesian AI Tells

### 1. Terlalu Formal / Kaku
AI Bahasa Indonesia sering terdengar seperti terjemahan atau surat resmi.

**Tanda:**
- Menggunakan "Anda", "Bapak/Ibu", "Saudara" di konteks casual
- Kalimat pasif berlebihan: "dapat dilakukan", "akan disampaikan", "telah diinformasikan"
- Kata sambung formal: "Selain itu", "Sebagai tambahan", "Dengan demikian"
- "Untuk itu", "Oleh karena itu", "Adapun", "Bahwa"

**Before (AI):**
> Halo, untuk informasi tambahan, bootcamp tersebut dapat diikuti melalui link berikut. Selain itu, terdapat promo early bird yang dapat dimanfaatkan.

**After (natural):**
> Oh iya, ada promo early bird lagi. Cek di sini ya: [link]

### 2. Singkat yang Pantes vs Singkat yang Kaku
Bahasa Indonesia casual itu berbeda jauh dengan formal. Pakai singkatan yang orang Indonesia beneran pakai di chat.

**Singkatan natural untuk chat/WA:**

|--------|---------|
| sudah | udah, dah |
| tidak | nggak, gak, ndak |
| dengan | dgn |
| untuk | buat, utk |
| sampai | sampe |
| juga | jg |
| karena | knp, krn |
| mau | mo |
| sudah selesai | udah kelar, udah done |
| bagaimana | gimana, gmn |
| sekarang | skrng |
| orang | org |
| kalau | kalo |
| bisa | bs |
| tetapi | tapi, tp |
| ini | ni |
| begitu | gitu, gtu |
| lihat | liat, cek |
| ingat | inget |

| mengoptimalkan | optimalin |

**Penting: jangan overuse singkatan.** Chat bisnis profesional tidak sama dengan chat teman. Pakai secukupnya, jangan setiap kata disingkat.

### 3. Pola Kalimat AI di Bahasa Indonesia

**"Saya ingin menginformasikan bahwa..."** → Langsung sampaikan saja.
**"Mohon maaf atas ketidaknyamanannya"** → Terlalu formal buat chat biasa.
**"Terima kasih atas perhatiannya"** → Cukup "Makasih ya" atau "Thanks".
**"Apabila ada pertanyaan, jangan ragu untuk..."** → "Kalau ada yang mau ditanya, langsung aja."
**"Kami sangat senang bisa membantu"** → "Bisa bantu, seneng banget."
**"Dengan senang hati"** → Hilangkan. Orang Indo jarang pakai ini di chat.

### 4. Em Dash / Tanda Baca Berlebihan
AI suka pakai em dash dan tanda baca formal. Di chat Indonesia:

- Pakai koma biasa, bukan em dash
- Bisa pakai titik dua (:) buat penjelasan singkat
- Tidak perlu titik koma (;)
- Paragraf pendek, 1-2 kalimat saja

### 5. Greeting yang Natural

**AI-style (hindari):**
> Halo [Nama], semoga harimu menyenangkan. Saya ingin menyampaikan...

**Natural:**
> Hai [Nama], Aji dari Akala.
> Siang [Nama] — Aji dari Akala di sini.
> [Nama] hai, Aji dari Akala.

### 6. Tone untuk WhatsApp Bisnis

Pendekatan personal di WA:
- Buka dengan nama mereka
- Langsung ke point, jangan basa-basi
- 1 pain point yang relevan, bukan list panjang
- Soft CTA (tanya, bukan perintah)
- Jangan lebih dari 5-6 baris per pesan
- Pakai emoji secukupnya (1-2, bukan dekorasi)
- Tidak perlu sign-off formal

### 7. Kata yang Overused oleh AI Indonesia

**Hindari kata-kata ini di konteks casual:**
- "tentunya", "pastinya"
- "memastikan"
- "memberikan" → pakai "kasih" atau "ngasih"
- "melakukan" → pakai "ngerjain", "lakuin", atau langsung kata kerjanya
- "mengenai" → pakai "soal", "tentang"
- "melalui" → pakai "lewat", "via"
- "mengenalkan" → pakai "kenalin"
- "memanfaatkan" → pakai "manfaatin"
- "mengoptimalkan" → pakai "optimalin"
- "berkolaborasi" → pakai "kolaborasi" tanpa ber-

## Contoh Full Before/After (WhatsApp Outreach)

**Before (AI-sounding):**
> Halo Kemal, saya Aji dari Akala. Saya melihat Anda mendaftar dalam waiting list bootcamp kami. Bootcamp ini dirancang untuk membantu peserta membangun skill automation yang dapat langsung diterapkan. Materi dimulai dari dasar hingga tingkat lanjut, dengan output berupa artifact yang dapat digunakan untuk portfolio. Apabila Anda memiliki pertanyaan, jangan ragu untuk menghubungi saya.

**After (natural):**
> Hai Kemal, Aji dari Akala. Saya liat kamu daftar di waiting list bootcamp kita. Materinya mulai dari nol, jadi nggak perlu khawatir kalau belum pernah coba n8n. Nanti pulangnya langsung punya workflow dan roadmap yang bisa dipakai. Mau saya jelasin lebih detail soal kurikulumnya?
